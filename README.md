# 嵌入式 Linux 智能家居控制终端 · Smart Home Terminal

项目背景：**学校组织的企业实训**（中科（安徽）康芯科技有限公司）。
产出一套跑在嵌入式 Linux 开发板上的智能家居中控终端——800×480 触摸屏、纯 C 实现界面，串联嵌入式中控、单片机从机与云端语音识别三层。

> 项目详细介绍（架构、协议、实现细节）见 [`docs/overview.md`](docs/overview.md)；
> 12 张屏幕实拍与演示视频见 [`media/`](media/)。

## 系统架构

| 层 | 硬件 | 职责 | 通信方式 |
|---|---|---|---|
| 人机交互层 | 嵌入式 Linux 开发板（800×480 电阻触摸屏） | 界面绘制、触摸响应、业务逻辑 | — |
| 传感执行层 | STM32 从机 | 3 路 LED、血压计、心率传感器 | 串口 `/dev/ttySAC2` |
| 智能服务层 | Ubuntu 服务器 | 语音识别：PCM 上传 → 返回命令码 | TCP socket |

程序入口 `./app <ubuntu-IP>`，启动即完成 LCD、触摸屏、串口、网络四大初始化。

## 四大功能

1. **相册** — 本地轮播 4 张 BMP，点击「下一张」循环切换，全屏 + 返回热区
2. **语音控制**（核心）— 按下麦克风 `arecord` 录 3 秒 PCM → 上传 Ubuntu 识别 → 返回命令码 → 执行动作

   | 命令码 | 动作 |
   |---|---|
   | 2 | 打招呼：屏显「你好吖」+ 播放问候语音 |
   | 3 | 测血压：向 STM32 发 `mks-sbp`，>139 提示「血压偏高」 |
   | 6 | 测心率：向 STM32 发 `mks-hr`，屏显数值 |
   | 100 | 全开灯光：三路 LED 齐亮 |
   | 999 | 退出语音模式 |
   | 其他 | 「我好像没听懂，请再说一遍」 |

3. **留言器** — `arecord` 录 5 秒 WAV → `aplay` 回放，当家庭留言板
4. **灯光控制** — 屏幕三个色块（红 / 绿 / 蓝）点击开关；串口发 `led1-on` / `led1-off` ASCII 文本命令

## 底层实现

- **帧缓冲直写**：`mmap /dev/fb0` 直接操作 ARGB 像素，不经任何图形框架
- **自写 BMP 解码器**：24 位 BGR→ARGB 转换、4 字节行对齐、越界自动裁剪
- **中文渲染**：加载 `/simfang.ttf` 仿宋字库，位图叠画到屏幕
- **触摸去抖**：20 ms 内同一位置判定为抖动丢弃；`lock_touch` 防连触误触
- **串口可靠查询**：`poll` 200 ms 超时 × 30 次重试，等待 STM32 回传
- **开机动画**：进度条逐帧 `fill_rect` 刷新

## 启动流程

```
main
 ├─ lcd_init()      LCD 初始化
 ├─ ts_init()       触摸屏初始化
 ├─ serial_init()   打开串口
 ├─ init_sock(IP)   连接语音服务器
 ├─ start()         欢迎页（组名：第八组）
 ├─ loading()       开机进度条
 └─ page_main()     主界面事件循环（四大入口）
```

## 关于可编译性（请先读这段）

`src/main.c` 是一个 **415 行的单文件主程序**，它是编译单元里**属于本项目的部分**。实训方提供的板级支持代码未包含在仓库内：

- `common.h` / `common.c` — 板级 BSP，提供 `lcd_init()`、`ts_init()`、`fontLoad()`、`fill_rect()`、`showbitmap()` 等基础接口（**版权属实训方**）
- 字库 `/simfang.ttf`、图片素材 `0720.bmp` / `07.bmp` / `06.bmp` / `10.bmp` — 运行期资源，同样未包含
- 交叉编译工具链与 NFS 挂载环境

所以**仓库单独拉下来无法直接编译**。界面绘制逻辑、BMP 解码、触摸去抖、串口协议、事件循环这些应用层实现都在 `src/main.c` 里，可以直接阅读。
