# 基于 STM32 与嵌入式 Linux 的智能家居控制终端 —— 项目文稿

> 底稿来源：`使用的代码.txt`（415 行 C 语言源码）+ 12 张屏幕实拍 + 演示视频
> 用途：PPT 内容底稿（Risograph 双色 Zine 风）

---

## 一、项目一句话

一块 800×480 触摸屏的嵌入式 Linux 开发板，通过**串口**指挥 STM32、通过**网络**连接 Ubuntu 语音服务器，跑一套**纯 C 手写 GUI**，实现相册、语音控制、留言器、灯光控制四大功能。

---

## 二、系统架构：三层分工

| 层 | 硬件 | 职责 | 通信方式 |
|---|---|---|---|
| 人机交互层 | 嵌入式 Linux 开发板（800×480 电阻触摸屏） | 手写 GUI、触摸响应、业务逻辑 | — |
| 传感执行层 | STM32 从机 | 3 路 LED、血压计、心率传感器 | 串口 `/dev/ttySAC2` |
| 智能服务层 | Ubuntu 服务器 | 语音识别：PCM 上传 → 命令码返回 | TCP socket |

主程序入口：`./app <ubuntu-IP>`，启动即完成 LCD、触摸屏、串口、网络四大初始化。

---

## 三、四大功能模块

### 1. 相册
- 本地轮播 4 张 BMP 图片，点击「下一张」循环切换
- 全屏显示 + 右上角「返回」热区

### 2. 语音控制（核心亮点）
按下麦克风 → `arecord` 录 3 秒 PCM → 上传 Ubuntu 服务器识别 → 返回命令码 → 执行动作：

| 命令码 | 动作 |
|---|---|
| 2 | 打招呼：屏幕显示「你好吖」+ 播放问候语音 |
| 3 | 测血压：向 STM32 发 `mks-sbp`，>139 提示「血压偏高」 |
| 6 | 测心率：向 STM32 发 `mks-hr`，屏显数值 |
| 100 | 全开灯光：三路 LED 齐亮 |
| 999 | 退出语音模式 |
| 其他 | 「我好像没听懂，请再说一遍」 |

### 3. 留言器
- `arecord` 录 5 秒 WAV → `aplay` 回放，家庭留言板

### 4. 灯光控制
- 屏幕三个色块（红 / 绿 / 蓝）点击开关
- 串口协议：发 `led1-on` / `led1-off`（ASCII 文本命令），STM32 执行并反馈

## 四、底层实现亮点（没有 GUI 库，全是手写）

1. **帧缓冲直写**：`mmap /dev/fb0`，直接操作 ARGB 像素，性能拉满
2. **自写 BMP 解码器**：24 位 BGR→ARGB 转换、4 字节行对齐、越界自动裁剪
3. **中文渲染**：加载 `/simfang.ttf` 仿宋字库，位图叠画到屏幕
4. **触摸去抖**：20ms 内同一位置判定为抖动丢弃；`lock_touch` 防止连触误触
5. **串口可靠查询**：`poll` 200ms 超时 × 30 次重试，等待 STM32 回传数据
6. **开机动画**：进度条逐帧 `fill_rect` 刷新，4ms 一步

## 五、启动流程

```
main
 ├─ lcd_init()      LCD 初始化
 ├─ ts_init()       触摸屏初始化
 ├─ serial_init()   打开串口
 ├─ init_sock(IP)   连接语音服务器
 ├─ start()         欢迎页（组名：第八组）
 ├─ loading()       开机进度条
 └─ page_main()     主界面事件循环（四大入口）
```
